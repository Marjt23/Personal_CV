# Marjorie Casilao — Personal CV

A responsive personal portfolio with a navy and soft blue palette, an editorial layout, angled portrait, floating chapter navigation with reading progress, serif headings, the original portrait, and verified CV content. Built with HTML, CSS, and vanilla JavaScript. No build process or dependencies are required.

## Preview

Open `index.html` directly, or run `python -m http.server 8000` in this directory and visit `http://localhost:8000`.

## Files

- `index.html`: semantic CV sections and verified contact links.
- `style.css`: design tokens, responsive layouts, focus states, reduced-motion support.
- `script.js`: expandable mobile chapter navigation, reading progress, current-section navigation state, and subtle section reveals.
- `images/profile.jpg`: original profile photograph.
- `favicon.svg`: personal monogram icon.

Google Fonts supplies Playfair Display and DM Sans; system serif and sans-serif fallbacks work offline. The site uses no contact service or analytics. Email and phone links open the visitor's configured applications.

## Deployment

For GitHub Pages, publish the repository root from the desired branch using Settings → Pages. For Vercel, import the repository, choose Other as the framework, leave the build command empty, and serve the root directory. All local paths are relative, including support for GitHub Pages project URLs.

## Content and provenance

Original source: https://github.com/Marjt23/Personal_CV

The original CV supplies the portrait, email, phone, skills, experience, and education. The GitHub profile link comes from the repository owner. No certifications, projects, additional employment, skill percentages, or social accounts have been invented.
