Release workflow

  1. Develop and build locally.
  2. Push a branch to create a Preview deployment.
  3. Review the Preview before merging into main.
  4. Verify the resulting Production deployment.

For the real failed build, the environment variable was missing in Vercel even though it was configured locally. Adding it to the intended Vercel environments and redeploying resolved the error.
